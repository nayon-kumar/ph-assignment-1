# TypeScript & OOP Assignment

This repository contains the solutions for the TypeScript problem-solving and OOP assignment.

## Files

- `solutions.ts` — implementations of all eight programming problems.
- `type-narrowing.md` — blog post about TypeScript type narrowing.
- `access-modifiers.md` — blog post about OOP access modifiers.

## Topics Covered

The code practices optional parameters, nullish coalescing, union types, `typeof` narrowing, readonly tuples, generics, interfaces, `keyof`, array methods, classes, inheritance, access modifiers, Promises, and asynchronous validation.

## Blog Posts

- [What Is Type Narrowing in TypeScript?](./type-narrowing.md)
- [Access Modifiers in TypeScript OOP](./access-modifiers.md)

## Run

Compile the TypeScript file with the TypeScript compiler:

```bash
tsc solutions.ts
```

The generated JavaScript can then be run in a JavaScript runtime that supports Promises and `setTimeout`.
